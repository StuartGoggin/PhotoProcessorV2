# PhotoGoGo 2.0.52 — Lightbox review filters and illustrated Help

## Review an event with fewer steps

- Filter the current folder by All, Needs review, Reviewed, Google-selected, Rated or Favourites. Control Trash separately and sort by capture time, filename, rating or original size. Counts, reset and remembered view preferences keep your place.
- A saved rating/tag, Trash/restore or Google selection/favourite change marks its capture Reviewed automatically. This includes Original, B&W, Enhanced and cropped versions. Browsing and zooming leave the flag unchanged.
- Press **M** to change Reviewed manually or **Shift+M** for Reviewed & next. Older photographs start Needs review without migrating historical ratings/selections.
- Navigation and controller browsing follow the same filtered order. Failed saves retain the current photograph. If the original decision saved but Reviewed did not, retry only Reviewed; the original change remains saved.

## Help beside your work

Open **Help & User Guide**, or **Help for this page**, for the illustrated offline guide: 18 chapters, 11 illustrations, search, adjustable text, larger figures and printing. Your current work stays open. Existing Lightbox F1 keyboard/controller help remains available.

## Testing and installation

Windows x64 test installers. Close PhotoGoGo after active Jobs finish before installing. Start with a small event and test the automatic/manual Reviewed workflow above, then open Help and return to the same photo. Version 2.0.51 remains the rollback build. These packages are unsigned, consistent with prior releases.

Validation includes 416 native tests, automatic-review failure/identity checks, a 760-original synthetic folder, existing Lightbox/controller/selection regressions, offline guide checks and installer payload inspection. Thirty opt-in media/hardware tests were not run. Target-PC behavior, subjective image quality and live Google service behavior remain separate acceptance checks. No software was installed or render interrupted during this release work.

See [the validation receipt](release-2.0.52-validation.md) for source identity, artifact hashes and evidence limits. Pinned media, metadata, RAW and controller source/licence deliverables are retained. The matching FFmpeg corresponding-source archive accompanies the release.
